探险岛（HTML 离线版）iPad 安装说明
====================================
版本：v0.12.5（2026-10-18）

一、把本文件夹传到 iPad
  1. 用 AirDrop / 微信文件传输 / iCloud 云盘把「探险岛-HTML离线包.zip」发到 iPad
  2. 在 iPad「文件」App 中找到它，点一下即可解压
  3. 注意：design 文件夹和 ios 文件夹必须保持在同一层
     （本包结构已固定，不要单独移动或删除文件，否则图标会显示成 ❓）

二、打开并添加到主屏幕
  1. 打开 iPad 的「文件」App，进入 ios → preview
  2. 长按 index.html → 选择「用 Safari 打开」
  3. Safari 打开后，点分享按钮（方框+向上箭头）→「添加到主屏幕」
  4. 以后从主屏幕的「探险岛」图标进入，全屏运行、无地址栏

三、离线游玩
  - 本游戏 100% 本地运行，打开一次后断网也能玩
  - 孩子的进度、金币、收集册自动保存在这台 iPad 上
  - 画面会自动等比缩放适配屏幕，横屏体验最佳；竖屏也能正常游玩

四、这一版怎么玩
  【主页】
  - 一条大棋盘：出发 → 识字村 / 思维镇 / 拼音谷 / 英语王国 / 天文台 / 环球号 → 终点城堡
  - 点任意学科格子 → 进入该学科的「关卡列表」

  【关卡列表】（本版新增，重要）
  - 按星区分组列出该学科全部 100 关，每关显示状态：
      ★★☆   已通关（星星数）
      进行中  下一关
      未解锁  先过前面的关
  - 点关卡 → 进入该关
  - 每张卡右下角「重玩」→ 只重玩这一关（已得的星星不会丢）
  - 右上角「🔄 从头开始」→ 清空【整个学科】的进度，从第 1 关重新玩
      （金币、其他学科、贴纸收集全部保留；要点两次确认，防误触）

  【关卡内】
  - 每个学科都是「先学一学，再练一练」：先一张知识卡，再出题考刚才学的
  - 天文台新增：木星的卫星（95+ 颗、伽利略 1610 年发现 4 颗）、
    土星的卫星（146+ 颗、泰坦、表面有液态甲烷湖）
  - 月相配了真周期动画：新月→蛾眉月→上弦月→盈凸月→满月→亏凸月→下弦月→残月
  - 关卡左下角「🔄 重玩本关」：只重玩当前这一关
  - 天文台题型 13 种：练一练 / 连一连 / 分分类 / 称一称 / 排排队 / 点点看 /
    看影子 / 望远镜找一找 / 照顺序 / 数一数 / 找一找 / 学一学 / 找规律
  - 每隔几关有「复习关」，每个学科最后有「Boss 大挑战」（3 颗心连续答题）
  - 点小喇叭听读音：拼音自动转中文同音字朗读，英语单词用英文语音

  【收集册】
  - 贴纸 / 汉字卡 / 拼音卡 / 单词卡 / 星空卡 / 地理卡 / 徽章
  - 在关卡里学过的东西会自动收进册子

五、家长须知
  - 无广告、无内购、无外链、无网络请求，数据只存在这台 iPad 上
  - 家长中心（主页右上角锁图标，需过算术门）：
      · 护眼时长管理：单次 / 每日 / 休息间隔三档
      · 金币收支明细（按来源，只读）
      · 「重置全部进度」：恢复出厂，所有学科清空
  - 只想清一个学科：用该学科关卡列表页右上角的「🔄 从头开始」，比「重置全部进度」更轻

六、本版相对上一版的改动
  - 新增「关卡列表」页（原来点学科直接跳到下一关，已通关的关进不去，无法重玩）
  - 新增「从头开始」（按学科整体重置）与「重玩本关」（单关重玩）
  - 天文台：修好顶部步骤条遮挡、月相改成真周期动画、新增卫星知识点
  - 天文台：减少「找规律」题（11 个减到 3 个），换成更多题型
  - 隐藏「科学岛」和「金币商店」（数据保留，后续可恢复）
  - 修复：4 步以上关卡金币条被挤出屏幕、长标题把学一学卡撑破

七、和原生 App 版的差异
  - 点读发音走 iPad 系统朗读（需关掉侧边静音键）
  - 程序生成的音效仅原生版提供，本版静音游玩
  - 内容与玩法以本 HTML 版为最新（原生 App 已冻结，见仓库 ADR-0003）

八、出问题时
  - 图标显示成 ❓：design 文件夹没和解压目录同级，重新完整解压一次
  - 页面空白：确认是从「文件」App 用 Safari 打开，而不是在其他 App 的内置浏览器里
  - 进度丢失：数据存在 Safari 本地存储，清除 Safari 网站数据会一并清掉
