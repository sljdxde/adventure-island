探险岛（HTML 离线版）iPad 安装说明
====================================
版本：v1.0.4（2026-10-26）

一、把本文件夹传到 iPad
  1. 用 AirDrop / 微信文件传输 / iCloud 云盘把「探险岛-HTML离线包-v1.0.4.zip」发到 iPad
     （包名带版本号；以后每次更新都是新名字，几个版本可以同时放在 iPad 上，不会混）
  2. 在 iPad「文件」App 中找到它，点一下即可解压 →
     解压出来的文件夹就叫「探险岛-HTML离线包-v1.0.4」，多版本各自的文件夹名不同，好区分
  3. 注意：进入这个版本文件夹后，design 文件夹和 ios 文件夹必须保持在同一层
     （本包结构已固定，不要单独移动或删除文件，否则图标会显示成 ❓）
  4. 换新版时：装好新版本文件夹并「添加到主屏幕」后，旧版本的文件夹可以整个删掉；

二、打开并添加到主屏幕
  1. 打开 iPad 的「文件」App，进入「探险岛-HTML离线包-v1.0.4」→ ios → preview
  2. 长按 index.html → 选择「用 Safari 打开」
  3. Safari 打开后，点分享按钮（方框+向上箭头）→「添加到主屏幕」
  4. 以后从主屏幕的「探险岛」图标进入，全屏运行、无地址栏

三、离线游玩
  - 本游戏 100% 本地运行，打开一次后断网也能玩
  - 孩子的进度、金币、收集册自动保存在这台 iPad 上
  - 画面会自动等比缩放适配屏幕，横屏体验最佳；竖屏也能正常游玩

四、这一版怎么玩
  【主页】
  - 一条大棋盘：出发 → 识字村 / 思维镇 / 拼音谷 / 英语王国 / 天文台 / 环球号 → 终点城堡
  - 点任意学科格子 → 进入该学科的「关卡列表」

  【关卡列表】（本版新增，重要）
  - 按星区分组列出该学科全部 100 关，每关显示状态：
      ★★☆   已通关（星星数）
      进行中  下一关
      未解锁  先过前面的关
  - 点关卡 → 进入该关
  - 每张卡右下角「重玩」→ 只重玩这一关（已得的星星不会丢）
  - 右上角「🔄 从头开始」→ 清空【整个学科】的进度，从第 1 关重新玩
      （金币、其他学科、贴纸收集全部保留；要点两次确认，防误触）

  【关卡内】
  - v0.13 起**进关就自动念**：学一学卡念「字 + 例词」，每道题先念题目、再念选项
      · 有文字的选项照念；只有图标的选项念「第 1 张、第 2 张」（不念内容，免得报答案）
      · 孩子一点选项，朗读立刻停；答错念一句提示，答对不念（有音效）
      · 听漏了孩子自己点关卡右上角的 🔊 重听整题
      · 不想听：家长中心 →「朗读（题目和选项）」关掉
  - 每个学科都是「先学一学，再练一练」：先一张知识卡，再出题考刚才学的
  - 天文台新增：木星的卫星（95+ 颗、伽利略 1610 年发现 4 颗）、
    土星的卫星（146+ 颗、泰坦、表面有液态甲烷湖）
  - 月相配了真周期动画：新月→蛾眉月→上弦月→盈凸月→满月→亏凸月→下弦月→残月
  - 关卡左下角「🔄 重玩本关」：只重玩当前这一关
  - 认钟表「拨一拨」：**用手指直接拖指针**（外圈长针拨分钟、中间短针拨小时），
    也可以点「－ 时 / ＋ 时 / 整点 / 半点」按钮，两种方式都对
  - 环球号「拼地图」：地图下方托盘里是**可以拖的轮廓块**（省份 / 大洲），
    拖到地图上对应的虚线位置、靠近就会吸住，六块 / 七块全部归位过关
  - 天文台题型 13 种：练一练 / 连一连 / 分分类 / 称一称 / 排排队 / 点点看 /
    看影子 / 望远镜找一找 / 照顺序 / 数一数 / 找一找 / 学一学 / 找规律
  - 每隔几关有「复习关」，每个学科最后有「Boss 大挑战」（3 颗心连续答题）
  - 点小喇叭听读音：拼音自动转中文同音字朗读，英语单词用英文语音

  【收集册】
  - 贴纸 / 汉字卡 / 拼音卡 / 单词卡 / 星空卡 / 地理卡 / 徽章
  - 在关卡里学过的东西会自动收进册子

五、家长须知
  - 无广告、无内购、无外链、无网络请求，数据只存在这台 iPad 上
  - 家长中心（主页右上角锁图标，需过算术门）：
      · 护眼时长管理：单次 / 每日 / 休息间隔三档
      · 金币收支明细（按来源，只读）
      · 朗读开关与语速（0.6-1.0）：关掉后整局不响，连 🔊 重听也不响
      · 「重置全部进度」：恢复出厂，所有学科清空
  - 只想清一个学科：用该学科关卡列表页右上角的「🔄 从头开始」，比「重置全部进度」更轻

六、本版相对上一版的改动
  - v1.0.4：**界面全面换新（视觉升级，玩法、进度、金币完全不变）**——
    1) 171 个图标全部重画：外面的关卡、导航、物品、小动物、吉祥物改成**绘本手绘风**
       （圆润可爱、深棕描边、水彩平涂、小脸蛋有腮红）；
    2) 题目里的天文、地理图标改成**写实风**：太阳、八大行星、月球、黑洞、彗星按真实
       颜色与光照绘制（地球像真实 🌍、火星像真实火星），中国/世界地图和各地地标也更逼真；
    3) 背景山丘、云朵、树木重绘为手绘分层风景；
    4) 动效更顺：按钮按下有回弹、关卡图标依次弹入，并尊重系统「减弱动态效果」设置。
       建议更新，孩子会更爱看。
  - v1.0.3：**三处缺陷修复**——
    1) 部分题目选项显示成问号：6 处「问号」图标换成有意义的图案，并给全部图标补了 emoji 兜底
       （个别图加载失败时显示有意义图案，不再是问号）；
    2) 家长中心「每日使用上限」可自己设置：默认 15 分钟，最小 5 分钟、每次 ±5 分钟，可选「不限时」；
    3) 全局排查并修正约 20 道天文题（正确答案原来答非所问）及 1 道数学排队题。
    建议更新。
  - v1.0.2：**打包规范**——离线包名与解压出来的文件夹都带版本号（如 v1.0.2），
    多版本可同时存放、好区分；游戏内容与 v1.0.1 完全相同，已装 v1.0.1 的不用重装
  - v1.0.1：认钟表「拨一拨」的钟面**可以用手指拨指针**了；补「当前 / 目标」两个时间，
    按钮也保留（外圈长针拨分钟、中间短针拨小时；分钟吸附整点/半点两档）
  - v1.0.1：**修好环球号「拼地图」拖不动**——地图托盘里现在有可拖的省份/大洲轮廓块，
    拖到虚线位置附近会自动吸住（原来只显示地图、一块都没有）
  - v0.13：新增**题目自动朗读**（进关就念；学一学卡 + 每题题面与选项；🔊 重听 + 家长开关与语速）
  - 新增「关卡列表」页（原来点学科直接跳到下一关，已通关的关进不去，无法重玩）
  - 新增「从头开始」（按学科整体重置）与「重玩本关」（单关重玩）
  - 天文台：修好顶部步骤条遮挡、月相改成真周期动画、新增卫星知识点
  - 天文台：减少「找规律」题（11 个减到 3 个），换成更多题型
  - 隐藏「科学岛」和「金币商店」（数据保留，后续可恢复）
  - 修复：4 步以上关卡金币条被挤出屏幕、长标题把学一学卡撑破

七、和原生 App 版的差异
  - 点读发音走 iPad 系统朗读（需关掉侧边静音键）
  - 程序生成的音效仅原生版提供，本版静音游玩
  - 内容与玩法以本 HTML 版为最新（原生 App 已冻结，见仓库 ADR-0003）

八、出问题时
  - 图标显示成 ❓：design 文件夹没和解压目录同级，重新完整解压一次
  - 页面空白：确认是从「文件」App 用 Safari 打开，而不是在其他 App 的内置浏览器里
  - 进度丢失：数据存在 Safari 本地存储，清除 Safari 网站数据会一并清掉
