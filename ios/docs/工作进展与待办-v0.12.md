## 九、v0.13 自动朗读（2026-10-19）

需求原话：「全部关卡及内容，需要增加一个念题目和选项的功能，不如4岁小朋友看不懂字的。就进入后就开始自动念」。

### 已完成（分支 `feat/v0.13-narration`）

- **进关即念**：学一学卡念「字 + 例词」，每道题先念题面再念选项；六科 600 关 2102 步全覆盖。
- **选项口径**：有文字的选项照念；只有图标的念「第 N 张」。

- **节奏**：进关那次点击的同步栈里开口（iPad 的手势解禁），之后每题渲染后 0.4 秒；
  孩子一点选项立刻停；答错念一句 `hint`，答对不念（已有音效）。
- **控制件**：关卡右上角 🔊「再念一遍」（800ms 没出声会脉冲提示，让孩子自己点）；
  家长中心新增「朗读开关 + 语速 0.6-1.0」，关掉后整局不响，状态随 `S.voice` 持久化。
- **静默降级**：`speechSynthesis` 不可用 / 被静音 / `?AISolve=1` 批跑，一律不出声、不报错。

### 研究结论（决定实现形状，别改回去）

见 `.scratch/v0.13-narration/research/01-ipad-tts-behavior.md`：

1. iPad WebKit **只在用户手势的同步栈里**解禁朗读，`setTimeout` 里的 `speak()` 会被静默丢弃
   → 进关那次点击必须同步开口，这就是 `enterLevel()` / `restartLevel()` 里 `voiceSpeakStep(true)` 的原因。
2. `cancel()` 后紧跟 `speak()` 会被吞（WebKit bug 191745）→ 打断与重念之间留 90ms；
   **禁止用 `onend` 串接下一条**（bug 238189 下 onend 不触发会永久卡死）→ 每题合成一句话，用标点控节奏。
3. 网页只能拿到 compact 音色；侧边静音开关会掐掉朗读且 JS 检测不到 → 家长中心写了「先看侧边开关」的提示。

  - 坐标用 `getBoundingClientRect()` 实测换算：`.frame` 被 `fitFrame()` 整体 `scale()`，写死像素会偏
  - 滚动冲突：`touch-action:none` + `preventDefault`，拖针时页面不跟着滚
- **拖动期间不重刷 svg**：只改 `#ckhandh` / `#ckhandm` 两条线的 `x2/y2`（`ckPaint()`）。
  重刷 innerHTML 会让 pointer capture 跟着被替换的节点一起失效，拖到一半就断。
- **歧义消掉了**：面板改成「当前 12:00 / 目标 9:30」两列并排 + 一行操作提示
  「手指拨指针：外圈长针拨分钟，中间短针拨小时」；按钮保留（手指不精准的孩子也能玩），

### 追加：拼地图一块都渲染不出来（数据字段与渲染端脱钩）

**症状**：环球号第 1 关「中国地图」只显示一张完整中国地图，托盘里没有任何可拖的块，
底部提示写着「拖着轮廓块回到虚线位置」，但根本没有块。第 7 关「七大洲拼图」同样。

**根因**（两层）：

1. **schema 脱钩**：`4ac00f1`（v0.11 双线合并）把渲染端改成了「真地图 `CHINA_MAP`/`WORLD_MAP` + 省份轮廓块」，
   `mappuzzleHTML` 只读 `st.pieces`（省份/大洲**名字**，再去地图里查路径）；
   而 `gen_content.py` 的 `mappuzzle_step()` 还在产出 `regions`（`id/label/color/points` 的假多边形）。
   渲染端 `pieces=[]` → 卡片 0 张、幽灵轮廓 0 个，一块都拖不动。
   复现路径（旧包）：环球号 → 第 1 关中国地图 → 托盘空白。
2. **静态闸门看不见**：`validate.py` 只校验 `regions` 非空和点数 ≥3，`regions` 一直在，所以一路绿灯；
   `preview_sweep.py` 只量盒模型，托盘为空也不越界。**这是「数据字段与渲染端脱钩」这一类缺陷的盲区。**

**修法**：

- `gen_content.py`：`mappuzzle_step()` 增加 `pieces` 参数并写进 JSON；中国章 6 块取面积最大、
  手指最好抓的「新疆 / 内蒙古 / 黑龙江 / 西藏 / 四川 / 广东」，世界章 7 块即七大洲。
  `regions` 字段保留（Swift 冻结点版本的解码仍依赖它，少字段会让原生端拼图变空）。
- `mappuzzleHTML`：托盘卡片宽度按块数自适应（原来写死 96px，6 块时第 6 块伸出 600px 地图外，7 块更放不下）。
- `mapDragStart/Move/End` **两处真 bug**：
  - 屏幕坐标直接当 `style.left` 用。整页被 `fitFrame()` 缩放到 0.87 后，卡片按缩放比走得不对，
    靠边的块（黑龙江、广东、大洋洲）永远进不了 55px 吸附圈。改成按 `wr.width/clientWidth` 折算；
  - 吸附判定原来混用 `getBoundingClientRect()`（屏幕口径）和 `pzTarget()`（布局口径），
    现在统一用布局坐标（`style.left + offsetWidth`）。
- **Boss 关布局**：Boss 把题面夹在上下两条血量行之间，可用高度只有常规关的一半（`.bb-step` 434，
  白色题卡 406），600px 地图 + 104px 托盘会把托盘顶出题卡。`mapSetup()` 里加了 `mapFit()`：
  量一次容器，按比例整体 `scale()`（Boss 里自然宽度也收到 520 / 托盘 88，缩放系数约 0.69）。
  注意 **不能先清空 `#mapwrap` 的 height 再量**——它的子元素全是绝对定位，清掉就塌成 0
  （第一版就是这么写的，Boss 拼图被顶到屏幕外，截图确认过）。
