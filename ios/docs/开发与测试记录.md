## 2. 关键技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 最低系统 | iOS 16.0 | 覆盖更老的 iPad；全程避开 iOS 17+ API（脚本扫描验证） |
| 持久化 | Codable JSON（Documents） | 不依赖 SwiftData(iOS17)/CoreData，迁移成本零 |
| 内容驱动 | 关卡=JSON（4 种步骤类型） | 家长加题不改代码；XCTest 自动校验答案正确性 |
| 实验物理 | 自研 `BuoyancyModel` 纯函数 + SpriteKit 渲染 | 物理与渲染解耦 → 可单元测试；不用 SKPhysicsBody（浮力需手写，纯函数更可控） |
| 音效 | AVAudioEngine 程序生成正弦蜂鸣 | 无音频素材依赖；静音键尊重系统 |
| 图标 | SVG 进 Asset Catalog + Emoji 兜底 | 资产缺失时 UI 仍可理解（测试覆盖兜底完整性） |
| 路由 | 自定义枚举 Route（非 NavigationStack） | 游戏式全屏切换 + 过渡动画更贴近设计稿 |
| 布局基准 | 4:3 横屏 1024×768 | 与设计稿画布一致，iPad only |

过程中自审发现并修复的问题（重要度排序）：

1. **SpriteKit 字典迭代中赋值** → 运行时崩溃风险。改为 keys 快照遍历。
2. **音效调度时间基准错误**（`AVAudioTime(hostTime:)` 是绝对时刻而非偏移）→ 改为 `mach_absolute_time() + hostTime(forSeconds:)`，否则全部音效叠加同时响。
3. **ForEach 重复 ID**（问号方块四铆钉用 UnitPoint.x 作 id 有重复）→ 改索引。
4. **步骤条编号用 firstIndex(first-match)**：语文关有"练一练"两步 → 两步都显示 2。改为显式传入序号。
5. **答题卡无内边距**（描边紧贴图标）→ 固定 165×165 卡面。
6. **比多少盘子只画 1 个物品**（占位残留）→ 改为 PlateGrid 数量排布（≤4 一行，>4 两行）。
7. **浮沉模型水面静止逻辑错误**（弹簧项把空中下落也吸向水面）→ 重写为"水面=0、入水后浮力+阻尼"两段式，语义与测试一致。
8. 主页学科 meta 文案与计数重复拼接 → 拆成 meta + unit。

## 5. 模拟器预览与第二轮修复（2026-09-29 晚）

为让用户在 Windows 上直接预览 iPad 效果，新增 `ios/preview/index.html` —— SwiftUI 工程的 1:1 浏览器模拟器（内嵌同源关卡数据、复刻 BuoyancyModel 同参数物理、图标取自 design/assets、进度存 localStorage）。访问：本地服务 `http://127.0.0.1:8932/ios/preview/index.html`（或直接双击文件，图标需保持相对目录结构）。

浏览器端逐屏实测（截图验证）：主页 → 识字第1关（认一认→练一练→大挑战→三星结算，金币 12→15）→ 数学第1关（点鸭计数 3 只→数字块）→ 实验室（猜浮→放苹果→物理收敛浮在水面→图鉴点亮→收进图鉴）→ 收集册（解锁状态正确）→ 家长中心（算术门→设置→进度）→ 休息遮罩（20 秒倒计时）。

**本轮浏览器实测发现并修复（双端同步）：**

| # | 问题 | 修复 |
|---|---|---|
| 9 | **"认一认"环节无下一步入口**——孩子认完字无法进入"练一练"（流程死路） | 认一认页右卡新增果冻绿按钮「练一练 ▶」；Swift `TeachStepView` 增加 `onNext` 回调 + `advanceStep()` |
| 10 | **浮沉结算过慢**：软木塞式弹跳约 3.5s 才触发"看现象"（判定阈值 \|v\|<26、\|y\|<60 过严） | 放宽为 \|v\|<45、\|y\|<90、稳定 0.3s，并加 **2.6s 强制结算** 兜底；Swift `FloatSinkScene`/模拟器同步（`ItemState.age` 字段） |
| 11 | 模拟器资产相对路径错误（preview 子目录多一层）→ 水管/金币回退为 emoji | `ICON_DIR` 与 hills 背景路径改为 `../../design/assets/` |
| 12 | **Swift 主页路径缺关卡节点与终点旗**（v1 实现只画了装饰点，与设计稿 final-01 不符） | `MapView` 新增 `PathLevelNodes`（识字村 10 关节点：完成✓绿/当前★发光/锁定灰，可点进入）+ 终点旗「终」 |
| 13 | 主页骰子按钮与礼物圆钮重叠 | 骰子移至 left:118px |

修复后重跑 `tools/validate.py`：**12 通过 / 0 失败**。

> 教训记录：Swift 端"编译通过"≠"流程可玩"。模拟器把状态机跑通后才暴露 teach 死路——这类**流程级缺陷**正是静态检查与单元测试的盲区，已加入手工验收清单第 2 条（走完 3 步关）。

## 6. 已知限制与二期

- 「写一写」PencilKit 描红未包含（原设计第四环节），地图关卡按 3 步走——二期用 PencilKit 笔顺引擎补上
- 实验仅「浮与沉」1 个（6 物品）；磁性/光影/物态需为新实验加专用场景（引擎与流程可复用）
- 语文「练一练」仅找字/找图两类题型；数学挑战关为文本比大小
- 英语王国入口为占位（二期）
- 音效为合成蜂鸣，正式版建议录制/下载童声音效包；TTS 读音建议换童声录音
- 图标为设计稿生成的扁平 SVG，若要 3D 感可在 Assets 原位替换高清图（代码不用动）
