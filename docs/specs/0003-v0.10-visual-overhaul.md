# v0.10 视觉专项：UI 改进方案

> 来源：2026-10-01 GitHub 开源调研 + 现有设计稿巡检。
> 实施口径：**仅 HTML 模拟器**（`ios/preview/index.html` + `design/*.html`），Swift 端冻结中（[ADR-0003](../adr/0003-html-simulator-first.md)）。文中 Swift 建议一律标注为「重建时」。

## 0. 先说调研结论：不要拿开源儿童教育 App 当视觉基准

GitHub 上「儿童教育游戏」这个池子的视觉水平**普遍低于我们现有稿子**。实测：`dhjz/hanzi-study`（227★，哪吒学汉字，最接近我们识字村的开源同类）的界面是白底粉块 + emoji + 系统字，关卡选择页比我们的 `final-02-chinese.png` 糙一个量级。开源教育项目的价值在**机制**（这部分 `design/research/` 两份文档已经吃透了），不在皮。

真正的可借鉴物在另外三个池子：

| 池子 | 代表 | 借什么 |
|---|---|---|
| 休闲游戏复刻 | Candy Crush / Duolingo / 马里奥派对反编译 | 构图、材质、路径节点画法、回合节拍 |
| CC0 美术资产库 | `Nieobie/game-icon-pack`、Kenney、Antura 资产 | 直接可用的图标与插画规范 |
| 开源字体 | OFL 中文儿童展示字 + SIL 识字字 | 一个品牌字都没有，这是最大的短板 |

## 1. 诊断：「丑」的八条根因（都有证据）

| # | 根因 | 证据位置 |
|---|---|---|
| 1 | **零品牌字体**。iOS 端走 `.system(design:.rounded)`，HTML 端 `--font-round` 兜到 `YouYuan/幼圆`（多数设备没有）→ 标题没有厚度、没有性格 | `Theme.swift:154-167`、`design/style.css:38` |
| 2 | **图标各自为政**。`IconView` 是手搓 SVG 集合，笔画粗细/圆角/视角不统一 | `Common.swift` |
| 3 | **「场景即界面」退化成「白卡浮在纯色上」**——正是 `design/ref.html` 规则①明令禁止的那件事。关卡页 80% 面积是一块白面板，天空/丘陵只占边缘一条 | `final-02/03/04.png` |
| 4 | **只有两层景深**（天空 + 面板）。头部产品是 4 层：远景/中景/近景道具/UI | 同上 |
| 5 | **等权构图，没有主焦点**。科学岛三栏等宽、收集册 6×2 网格——5 岁孩子不知道该看哪儿 | `final-04.png`、`final-05.png` |
| 6 | **空状态裸露 + 成人向元信息**。"还没有发现..."、"4-5岁 L2"、"关卡进度 5/40"、环节序号、底部重复提示条，五层元信息抢内容 | `final-03/04/05.png` |
| 7 | **骰子是假的**。设计稿 `mario-party-mechanics.md:270` 明确要求「立方体 + 旋转 0.8s 渐停 + 落定音效」，实现降级成「随机换点数 10 次 + 静态 10° 倾斜」——**规格没错，实现偷懒了** | `BoardView.swift:445-459`、`index.html:1104` `.bdie` |
| 8 | **棋盘格不是物体**。64px 渐变圆片 + 白边 + 图标，格子之间**没有路**，读不出"走"；已走过 = 降饱和，很廉价 | `index.html:179-186` `.bspace` |

## 2. 分档：按「观感提升 ÷ 工作量」排序

```
档 A 质感层  ▓░░░░░░░░░  0.5-1 天   只改 CSS/Theme，不动布局  →  观感 +40%
档 B 构图层  ▓▓▓▓░░░░░░  2-3 天    重排 5 类页面             →  观感 +80%
档 C 生命层  ▓▓▓▓▓░░░░░  3-4 天    骰子 + 动效 + 场景化棋盘   →  「傻」→「好玩」
```

**建议三档都做，但严格按 A→B→C 顺序**：A 的收益/成本比高到不成比例，做完 A 再评估 B 是否还需要那么大动作。

## 3. 档 A：质感层

### A1 字体（单条最高杠杆）

| 用途 | 字体 | 许可 | 备注 |
|---|---|---|---|
| 标题 / 学科名 / 答案数字 | **站酷快乐体**（`googlefonts/zcool-kuaile`）或 **站酷庆科黄油体**（`googlefonts/zcool-qingke-huangyou`） | OFL-1.1 | 都是简体、专为儿童/游戏气质设计、Google Fonts 官方分发。快乐体偏手绘俏皮，黄油体更厚更"游戏 Logo"——**探险岛的标题更适合黄油体**，二选一前先出对照样张。只做展示，正文别用（小字号可读性差） |
| 数字 / 拉丁 / 拼音 | **Fredoka** 600-700 | OFL | 圆润粗体，和站酷系气质一致 |
| 拼音标调 | **Andika** | OFL-1.1 (SIL) | 专为识字学习者设计，单层 `a`/`g`，拼音变音符号完整 |
| 田字格描红示范 | **霞鹜文楷 GB**（`lxgw/LxgwWenkaiGB`，1483★）或马善政毛笔楷书 | OFL-1.1 | 楷体，v0.9 工单 01 的写字引擎直接对口 |
| 正文 | 保留系统苹方 | — | 可读性优先，不换 |

> 另可试：`Des-Magmeta/ChildFunSans-Fusion`（OFL-1.1）= Stick + Child Fun Sans + 站酷快乐体的混编儿童字，一套覆盖中英，但只有 5★、未经大规模验证。

**⚠️ 硬约束：中文字体必须子集化。** 站酷快乐体全量 ~4MB，iPad 首屏不可接受。识字村 30 字 + 全 UI 文案约 500 字，`pyftsubset` 后 <120KB。做法：构建期从 `CONTENT` 里抽全部汉字生成 `--text=` 清单，产出 `zcool-subset.woff2`。

### A2 图标：换成统一图标系统

`Nieobie/game-icon-pack`（688★，**CC0-1.0**，800+，SVG+PNG，**全圆角无尖角**）。分类正好覆盖我们的词汇表：Game（含骰子、金币）、Nature、Food、Buildings、Symbols（含 `＋－×÷`，思维镇直接能用）、UI（含锁、勾、问号、刷新）。

落地方式：它默认是单色剪影——**借它的「形」（圆角半径、笔画粗细、视角统一），色仍走我们的品牌色**。替换 `IconView` 里手搓的 coin / star / gift / mushroom / home / question / check / dice / lock 九个高频图标即可，其余渐进替换。

### A3 控件质感统一（「果冻三件套」）

现在 `.broll`、`.tab.active`、`.slot.got` 已经是果冻质感，但 `.panel`、`.bdie`、数学题的三个答案金块**不是**——同一屏里两套语言，这就是"廉价感"的来源。统一成：

```css
.jelly {
  background: linear-gradient(180deg, <L1>, <L2> 45%, <L3>);
  box-shadow: inset 0 3px 0 rgba(255,255,255,.5),   /* 顶部内高光 */
              0 5px 0 <L4>,                          /* 底部硬色边 */
              0 8px 14px rgba(84,66,58,.18);         /* 落地投影 */
  border: 4px solid #fff;
}
.jelly:active { transform: translateY(4px); box-shadow: inset 0 3px 0 rgba(255,255,255,.5), 0 1px 0 <L4>; }
```

### A4 卡通描边标题字

现在标题是纯色粗体字，头部产品是**描边 + 双层阴影的厚字**：

```css
.kid-title {
  -webkit-text-stroke: 6px #fff;
  paint-order: stroke fill;
  filter: drop-shadow(0 3px 0 rgba(122,74,0,.35));
}
```

## 4. 档 B：构图层

### B1 关卡页：从「左右双栏」到「单焦点舞台 + 四层景深」

```
现在：  [天空条]  ┌─左卡─┐ ┌─右卡─┐        ← 两块等权白面板
改成：  ┌─────────────── 远景：天空/云/太阳 ───────────────┐
        ├─────────── 中景：丘陵/树/建筑剪影 ───────────┤
        ├───── 主舞台 60%：题目发生的那块「地」 ─────┤
        ├───── 近景：草/石/栅栏压住底边 ─────────────┤
        ─ 侧栏 25%：角色气泡（唯一指令位）+ 金币 ───┘
```

- 题目文字不再用白卡上的黑字，改由**木牌 / 石碑 / 云气泡**承载——文字是场景里的物体。
- **删掉**：`关卡进度 5/40`、`4-5岁 L2`（挪进家长中心）、底部重复提示条。指令只留角色气泡一处。
- 环节步骤条（玩/认/练/写）保留但图标化，缩到右上，不占文字带宽。

### B2 数学点数题（`final-03`）

鸭子现在是一排等距贴在浅蓝矩形上——是"图标列表"不是"池塘"。改：水面两层波纹 SVG + 睡莲错落，鸭子**近大远小、前后遮挡、轻微浮动**；点中一只，头顶浮 `+1` 气泡并计入 `已数`。三个答案金块换成**荷叶上的数字石**——金块是金币砖的语汇，用在这里语义打架。

### B3 科学岛（`final-04`）

三栏等宽 → **中央大水箱占 60%**（真的水：入水涟漪、上浮/下沉有过程动画，物品浮在**水面**而不是浮在米色卡上）。工具箱改成底部横向大图标托盘；图鉴改成可拉出的抽屉，不要常驻两格"还没有发现..."。

### B4 收集册（`final-05`）

现在是电子表格。改成**展示柜 / 小屋墙**：
- 空格不用虚线框 + 问号，改**淡色剪影**（silhouette）——给期待感，不给未完成感。
- 已收集卡：厚白边 + 随机微旋转（-3°~+3°）+ 图钉或胶带，像真贴上去的。
- 顶部放孩子头像 + 吉祥物站在柜子旁边，而不是一个 40px 的 avatar chip。

### B5 棋盘：从「悬空圆片」改成大富翁式环形赛道 ★已出 demo

`design/07-board-monopoly.html`（可点「掷骰子」实玩）。对照截图：`design/shots/v0.10-board-old.png` / `-new.png` / `-new-roll.png`。

现状的问题：8-10 个 64px 渐变圆片浮在一块米色面板上，格子之间只有一条白色虚线，**读不出"走"**；城堡是一个孤立在左下角的小图标；走过的格子降饱和，很廉价。

从真实大富翁棋盘借的四条骨架：

| 大富翁 | 我们对应做法 |
|---|---|
| **环带即赛道**——40 格不是"点"，是一条连续的路 | 画一条 56px 沙石环带（圆角矩形描边），格子铺在环带上。路本身就是棋盘 |
| **地契砖**——每格 = 外侧色带（社区色）+ 内侧米白身体（图 + 名 + 价） | 类型色带 + 图标 + 中文名（题目/金币/宝箱/蘑菇/休息），一眼分得清 |
| **四角锚点格**（GO / 监狱 / 免费停车 / 进监狱），尺寸略大 | 左下角 = 起点（绿色 + GO + 前进箭头），末格 = 回城堡（红色 + 旗）；环带按格数自适应：n 格 = 4 角 + (n-4) 边格，顺时针底→右→顶→左均分 |
| **中央空地放 logo + 两叠卡** | 中央放村庄场景 + **终点城堡**（从左下角的孤立图标升格为棋盘的地标）+ 星轨进度 + 骰子木托盘 |
| 环内侧一条金额带做设计感收边 | 星轨 + 内圈虚线带承担同一职责 |

刻意偏离（重要，别照抄）：
- **格子全部正立不旋转**。大富翁四面朝内是为四人围坐，5 岁孩子单独玩时左侧格子倒过来是纯噪音。
- **不做 40 格**。单关 8-10 格、2-4 分钟是注意力红线。
- **走过的格不降饱和**。改成色带转灰 + **路上留一串脚印**，格子本体保持可读。
- **骰子在中央木盘里，不在按钮上**。原来骰子贴在胶囊按钮左边，是个"图标"；现在是托盘里的实物，掷完留在盘里。
- **最后一格角色跳进中央城堡**——让大富翁的中间空地真正有用途，而不是装饰。

格型对照：

| 格型 | 现在 | 改成 |
|---|---|---|
| 题目格 | 黄渐变圆片 + 问号图标 | 黄带地契砖 + 问号砖图标 |
| 金币格 | 蓝渐变圆片 + coin | 蓝带砖 + 金币堆 |
| 宝箱格 | 紫渐变圆片 + gift | 紫带砖 + 宝箱 |
| 蘑菇格 | 珊瑚渐变圆片 + mushroom | 红带砖 + 蘑菇丛 |
| 休息格 | 绿渐变圆片 + home | 绿带砖 + 长椅/屋 |
| 起点 | 无（只有一个浮空旗） | 大号锚点格，绿带 + GO + 箭头 |
| 终点 | 浮空城堡小图标 | 升格为**中央地标城堡** + 末格"回城堡" |

## 5. 档 C：生命层

### C1 骰子 —— 模拟器用 CSS 3D 立方体（不需要物理引擎）

现在 `.bdie` 是 64px 白色圆角方块 + 点位，`rollDie()` 换 10 次点数。CSS 3D 变换在 iPad 上是 GPU 合成的，做真立方体的成本比想象低得多：

```css
.die      { transform-style: preserve-3d; transition: transform .26s cubic-bezier(.2,.9,.3,1.2); }
.die .f   { position:absolute; inset:0; border-radius:14px; }        /* 面用 A3 果冻质感 */
.die .f1  { transform: rotateY(  0deg) translateZ(32px); }
.die .f2  { transform: rotateY( 90deg) translateZ(32px); }
/* …f3..f6；点位用 radial-gradient 做凹陷，不是纯黑圆点 */
```

**五段节拍**（已在 `design/07-board-monopoly.html` 实做并逐帧验证；总时长 1.30s）：

| 段 | 时长 | 动作 | 缓动 |
|---|---|---|---|
| 1 蓄力 | 120ms | 骰子 scale 1→1.15、上移 18px；**影子同步缩小变淡**（scale .6 / opacity .14） | ease-out |
| 2 抛出 | 480ms | 绕 X 累计 +360°、绕 Y 累计 +720°（**两轴不同速才像翻滚**，同速只会像转盘） | `cubic-bezier(.16,.72,.3,1)` |
| 3 落地 | 90ms | squash：scaleY .84 / scaleX 1.14；影子瞬间放大变实（scale 1.25 / opacity .44） | ease-in |
| 4 回弹 | 220ms | 一次 overshoot 回正 | `cubic-bezier(.3,-1.4,.6,1)` |
| 5 定格 | 260ms | 数字气泡 + 屏震 3px×4 | — |

> 实测校正：原估的「抛出 260ms + 720°/1080°」太快（约 5300°/s，糊成一团看不清点数）。改成 480ms + 360°/720° 后翻滚可读且仍有重量。
> 另需一个 `.die-tilt` 外层常驻 `rotateX(-14deg) rotateY(-9deg)`：骰子落定后保持微倾，同时露出 3 个面——正对镜头的立方体看起来仍是 2D。

**实现要点：结果先定后演。** 掷的瞬间就 `r = random(1,6)`，动画只负责把 `r` 那一面转到正面——所以永远不会卡在"立着"的状态，也不需要物理收敛超时兜底。这是所有休闲游戏的做法，观感和真物理无差。**注意别在每次掷骰前把 cube 的 transform 重置回目标姿态**：那会闪一帧新点数；只让累计角度单调递增即可连续翻滚。

再加一个**骰子托盘**（有厚度的木盒）：骰子落在托盘里而不是悬在按钮上，符合"场景即界面"。

**Swift 端重建时**：SceneKit（系统框架，零依赖，iOS 16 可用）——`SCNBox(cornerRadius:)` 做圆角骰 + 6 面点位材质 + `physicsBody.applyTorque(SCNVector4(1,2,-1,1), asImpulse:true)` + 地面/四面墙 physicsBody 当托盘，顶部斜视相机。完整可运行范例见 `profburke/DiceRollDemo`（`GameViewController.swift`）。注意真物理需要 1.6s 未收敛就吸附到最近面的兜底。

### C2 角色走格

现在 `@keyframes bhop{45%{margin-top:-30px}}` —— 用 `margin` 做动画会触发重排，且没有重量感。改 `transform: translateY()`，每一跳：起跳 squash → 空中 stretch → 落地 squash + **影子随高度缩放**（跳最高时影子最小最淡）。落格那一格闪一下涟漪，金币格额外喷 4-6 个粒子。

跳与跳之间 340ms，最后一跳前**停 120ms**（ anticipation），落点才有力。

### C3 庆祝与反馈

## 7. 明确不做

- **不引引擎**（Unity/Flutter/three.js）。SwiftUI + SpriteKit + CSS 够用，全 3D 场景的性能与工作量都不划算。
- **不动 v0.8 骨架**。棋盘 + 金币总线是 ADR-0001/0002 定过的，本专项只改皮和手感。
- **不内嵌全量中文字体**。见 A1 硬约束。
- **不拿开源儿童教育 App 当视觉参考**。见 §0。
- **不给 3-6 岁加"关卡进度/年龄标签"这类成人元信息**——是删，不是美化。

## 10. 2026-10-01 追加：天文台不是识字课，题目不能一句话问二十遍

试玩连着提了两件事，指向同一个病根——**内容薄**：

1. 「拼一拼 `b — o = ?` 我还以为是减法」→ 破折号被读成减号，且题面本身写成算式。
2. 「闯关几乎都是相同的题目重复出现」→ 量出来的确凿证据：数学 100 道题只有 43 句不同问法（75% 重复），英语 61%、天文 61%；**同一关棋盘上连着三格问同一句话**（`池塘里有几只小鸭（点一点，数数看）` 在 math-0 出现 3 次）。
3. 「天文不是识字，我要的是上海天文馆那种：认识太阳系、8 大行星比重量、比引力、比自转公转周期」→ 老版十个关卡全在问「哪个是太阳」，考的是图标再认，不是天文。

### 10.1 天文台重做成太阳系课程（12 关 + 复习 2 + Boss）

| 关 | 主题 | 数据维度 |
|---|---|---|
| 1 | 太阳系是一家 | 1 恒星 + 8 行星；太阳直径 109 个地球、占全家质量 99.8% |
| 2 | 行星的座位表 | 距日 58 → 4515 百万千米 |
| 3 | 谁是巨无霸 | 直径比、1300 个地球才填满木星、卫星数 |
| 4 | 比一比轻重 | 质量（地球=1）：木 318 / 土 95 / 火 0.11 |
| 5 | 称一称 | 表面引力：木星 2.53 倍、月球 1/6 |
| 6 | 一天有多长 | 自转周期：木 10 小时 ←→ 金 5832 小时 |
| 7 | 一年有多长 | 公转周期：水 88 天 ←→ 海王 165 年 |
| 8 | 冷与热 | 表面温度：金星 464℃ 最热（不是水星） |
| 9 | 谁戴光环 | 土星环、木星大红斑、天王星躺着转 |
| 10 | 矮行星与彗星 | 冥王星 2006 降级、流星=小石头烧起来 |
| 11 | 月亮变胖变瘦 | 月相顺序、月亮不发光、潮汐 |
| 12 | 离开地球 | 恒星与光年 + 东方红 1970 / 神舟 2003 / 祝融 2021 |

数据口径 NASA Planetary Fact Sheet，取整到 5-6 岁读得动的量级（引力说成「10 斤称出 25 斤」）。

### 10.2 为教学新增的视觉与题型

- **天体不是图标**：`BODIES` + `bodyHTML()` 用 CSS 画行星——半径比按真实直径（`bodySize` 开 0.42 次方压缩，否则水星只剩几个像素）、土星两道弧画前后环、木星条纹 + 大红斑、地球两块大陆、月球环形山。收集册「星空卡」同步换成 12 张真天体（`{body}` 优先于 `{icon}`）。
- **月相** `moonPhaseHTML(p)`：亮盘 + 左半暗框 + 一条半轴 `R·|cos2πp|` 的晨昏线椭圆，`p<0.5` 是眉月（椭圆取暗色）、`p>0.5` 是盈凸（椭圆取亮色），下半月整体 `scaleX(-1)`。朔望上弦下弦一次到位。
- **新题型 `cmp`（比一比数据）**：一行一个天体（圆盘 + 名字 + 条 + 数值），**点一行就是作答**——数据本身就是教具。`viz:"disc"` 用圆盘大小讲「比大小」，`viz:"bar"` 讲周期/质量/温度。跨度超过 12 倍自动改**对数刻度**（10 小时 vs 5832 小时线性画短的那条会消失），并在卡片下写明「条长按对数刻度，数值看右边」。
- **`order` 长出第二副面孔**：原来只排数字，现在支持 `items:[{body|phase|icon, name, v}]`——按真实值排序、按标签显示，于是有了「离太阳由近到远排一排」「月亮从新月长到满月排一排」。
- **`letter` 开场卡**加 `body` + `stats`：大圆盘 + 三条数据（直径/质量/卫星数），开场就是天文学而不是认字。
- `quiz/listen/pattern/memory` 的选项统一走 `optVisual()`，都能吃 `body`/`phase`。

### 10.3 拼读不再是减法

`blendHTML` 的 `—` 连接符换成**实心 ⊕ 徽章压在两张倾斜贴合的卡片上**，外面套虚线「配对框」，结果用 `⇒` 并在下方标注「合起来」，答对后虚线槽转实线绿。题面七处 `拼一拼：b — a = ?` 全部改写成「b 和 a 手拉手，变成哪个音？」这类说法。顺带把 `blend` 借给英语做**音节拼词**（`b + anana → banana`），字号按最长音节自动缩。

### 10.4 题面去重：闸门 + 换说法 + 换题型

- **闸门**：`audit_content.py` 加规则 8「同一关棋盘上，题面一句话不许出现两次」，另加规则 6（天体圆盘 ↔ 名字）、规则 7（cmp 答案必须是该组数据的极值，`ext` 字段与 `validate.py` 双向核对）。首跑揪出 28 项，全部修完归零。
- **换说法**：数学九套数数场景各配三句问法（`SC()`），拼音/识字/英语的模板题进问法池按关卡号轮转（`CN_ASK_MORPH`、`EN_ASK_FIND/PIC/HOW`）；`Q_ALT` + `dedupe_questions()` 兜底把同关撞句的题换成同义问法。
- **换题型**：数学补位题不再「再数一遍道具」，改成优先补本关没出现过的题型（`MATH_FILL` 轮转 pattern/split/neighbor/order/compare/classify/dice）——count 从 38 道降到 32 道，pattern 从 3 道升到 12 道。英语把四种组合扩成六种，新增 `en_count`（英语问数量）与 `en_blend`（音节拼词）。
- 复习/Boss 关的旧题混排（`sample_questions`）按题面去重——之前 boss 里「数一数有几颗行星」会出现两遍。
- 结果：不同问法占比 数学 43%→52%、英语 51%→70%、天文 50%→75%、拼音 72%→75%、识字 68%→71%；**同关重复率归零**（闸门常驻）。
