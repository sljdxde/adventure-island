从大富翁棋盘借了什么

  • 环带即赛道：真实大富翁的 40 格不是"点"，是一条连续的路。我们原来是 8-10 个悬空圆片，孩子读不出"走"。现在格子铺在一条沙石环带上，路本身就是棋盘。
  • 地契砖格：大富翁每格 = 外侧色带（社区色）+ 内侧米白身体（图 + 名 + 价）。我们改成 类型色带 + 图标 + 名称，一眼分得清题目格/金币格/宝箱格。
  • 四角锚点：大富翁四角是 GO / 监狱 / 免费停车 / 进监狱，尺寸略大。我们把起点放左下角、转角给事件格，节奏感就出来了。
  • 中央主题区：大富翁中间是 logo + 机会/公益金两叠卡。我们中间放村庄场景 + 终点城堡（原来是浮在左下角的一个小图标）+ 星轨进度。
  • 内圈细带：大富翁环内侧有一条金额带做"设计感收边"。我们用星轨 + 木牌标题承担同一职责。

刻意偏离大富翁的地方

  • 格子全部正立不旋转。大富翁四面朝内是为四人围坐，我们这里左侧格子倒过来对 5 岁孩子是纯噪音。
  • 不做 40 格。单关 8-10 格、2-4 分钟是注意力红线，环带按格数自适应铺满。
  • 走过的格不降饱和。原来 .passed{opacity:.5;filter:saturate(.5)} 很廉价，改成色带转灰 + 路上留脚印，格子本体保持可读。
  • 骰子在中央木盘里，不在按钮上。原来骰子贴在胶囊按钮左边，是个"图标"；现在是托盘里的实物，掷完留在盘里。

骰子五段节拍（1.04s）

  • ① 蓄力 120ms：骰子 scale 1→1.15、上移 18px，影子同步缩小变淡（没有这条就完全没有重量）
  • ② 抛出 260ms：绕 X 转 720°、绕 Y 转 1080°——两轴不同速才像翻滚，同速只会像转盘
  • ③ 落地 180ms：squash（scaleY .86 / scaleX 1.12），影子瞬间变大变实
  • ④ 回弹 220ms：±8° 一次过冲收尾
  • ⑤ 定格 260ms：目标面朝上 → 数字气泡 + 屏震 2px×3
  • 结果先定后演：掷的瞬间就出 r，动画只把 r 那面转到正面。所以永远不会卡在"立着"，也不需要物理引擎兜底。

这一屏还顺带做了

  • 品牌字：标题/数字换站酷庆科黄油体（OFL-1.1）+ Fredoka，标题加 5px 白描边 + 硬阴影厚字处理。落地时中文子集化，全量 4MB 不上线。
  • 四层景深：天空 / 远丘 / 草带 / 棋盘，UI 浮在场景上而不是白卡浮在纯色上。
  • 删掉的元信息：关卡进度 3/10、环节序号条、底部重复提示条——3-6 岁一条都不需要，指令只留一处。
  • 走格动效：从 margin-top 改 transform，起跳压扁→空中拉长→落地压扁→小回弹，影子随高度缩放。
