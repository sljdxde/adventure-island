# 探险岛 · 幼小衔接 iPad App

面向自家孩子的 3-6 岁幼小衔接学习 App，**仅个人使用、不上架**。

- `design/` HTML 交互设计稿（马里奥风 v6 定稿，`shots/final-*.png`）+ 竞品审美参考
- `ios/` SwiftUI + SpriteKit 原生工程（iPad / iOS 16 / 仅横屏），构建与测试见 [ios/README.md](ios/README.md)，开发与测试全过程见 [ios/docs/开发与测试记录.md](ios/docs/开发与测试记录.md)。**Swift 端自 2026-09-30 起暂缓（见 [ADR-0003](docs/adr/0003-html-simulator-first.md)），新功能只落在模拟器**
- `ios/preview/index.html` App 浏览器模拟器（无需 Mac 即可试玩完整流程）——**当前唯一实现端与验收载体**：五学科全部迷你棋盘化（掷骰走格 · 途经必答题 · 复习/boss 关）· 金币账本商店（角色/称号）· 结算仪式

> 学科（6 水管）：识字村（语文 18 关）· 思维镇（数学 18 关 · 8 种题型）· 拼音谷（15 关）· 英语王国（15 关）· 天文台（13 关）· 科学岛（浮沉实验）——每学科含 2 复习关 + 1 boss 大挑战 · 收集册 7 组 + 衣橱 · 家长中心（护眼时长/算术家长门/金币统计）· 全程可静音游玩（飞机模式友好）
