# 探险岛 · 幼小衔接 iPad App

面向自家孩子的 3-6 岁幼小衔接学习 App，**仅个人使用、不上架**。

- `design/` HTML 交互设计稿（马里奥风 v6 定稿，`shots/final-*.png`）+ 竞品审美参考
- `ios/` SwiftUI + SpriteKit 原生工程（iPad / iOS 16 / 仅横屏），构建与测试见 [ios/README.md](ios/README.md)，开发与测试全过程见 [ios/docs/开发与测试记录.md](ios/docs/开发与测试记录.md)
- `ios/preview/index.html` App 浏览器模拟器（无需 Mac 即可试玩完整流程）
