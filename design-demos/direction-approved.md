2026-10-26

## 展示的方案
- 方向 A：粗描边贴纸风（贴纸大冒险）
- 方向 B：软糖果冻风（软糖乐园）
- 方向 C：绘本手绘风（童话绘本）
- 风格板：`design-demos/三方向风格板.html`

## 用户选择（原话）
> 「我更倾向于 C 的手绘风格，但是你的图案、图标要更加优质。外部的关卡这里，可以可爱一点。
> 具体到题目内部的，比如天文馆、地理等等，图标应该更加写实，地球像真实🌍，火星像真实火星这样。」

## 确定的设计语言（双层）
1. **框架层（外部 / 关卡选择 / 导航 / 通用物品 / 吉祥物 / 装饰）**：
   方向 C 绘本手绘风——手绘深棕描边、水彩/蜡笔平涂、纸张质感、温暖可爱。
2. **内容层（学科题目内部，尤其天文馆、地理等科学内容）**：
   写实图标——真实色彩、球体光照、大气光晕；地球像真实地球，火星像真实火星。

## 执行要点
- 图标按文件名复用（`ic(name,size)` 读 `design/assets/icons/{name}.svg`），重绘 SVG 内容即可全局生效。
- 用图标生成器（Python → SVG）统一批量产出，保证风格一致、可复现。
- 写实天体：径向渐变（单侧光源）+ 表面纹理 + 大气边缘光晕，取代旧的上下线性渐变。
- 手绘框架：统一深棕描边、圆润形状、水彩平涂、纸张纹理。
- 完成后过 check_registry / validate / audit_preview 三闸门，再打包。
