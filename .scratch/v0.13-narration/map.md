# 探险岛 v0.13 自动朗读

## Destination

iPad 上打开 HTML 离线包，进入任何一关、任何一道题，都自动把「学一学」卡和题面念出来，
让还不识字的 4 岁孩子能独立玩完一关；每个题面有「🔊 再念一遍」，家长中心能一键关掉朗读。
交付物是改过的 `ios/preview/index.html` + 重打的 `探险岛-HTML离线包.zip`。

## Notes

- 仓库规则：只做 HTML 侧（AGENTS.md §1「HTML 优先，Swift 不新做」）；Swift 原生端不接这个需求。
- 改动顺序：`gen_content.py` → `gen_preview_data.py` → `check_registry.py` / `validate.py` / `audit_preview.py` 三门闸门。
- 技术底座已经有了：`index.html` 里的 `speak(t, sub)` 做了学科路由（英语/天文中英分段、拼音转同音字），
  这件事的难点不是发声，是「每类题念什么」和「什么时候念」。

### 建图前 grilling 已锁定的口径（不单开票，改口径要回到这里改）

1. 范围：六科 100 关全开；自动念做成渲染层通用钩子，不按学科开关。
2. 只念「学一学」卡和每道题的题面；不念结算、金币、表扬（已有音效与动画）。
3. 选项：有文字的念文字；图标选项只念序号（「第 1 张」），不念图标语义。
4. 节奏：进关直接念第一题（不念关卡名）；每题渲染后 0.4 秒开念；孩子一点选项立刻停；
   答错念一句短提示，答对不念。
   ※ 票 01 修正（2026-10-19）：iPad WebKit 只在用户手势的同步栈里解禁朗读，0.4 秒的定时器解禁不了。
   所以**进关那一下点击里必须同步解禁并念第一题**，之后各题才走 0.4 秒延时。
5. TTS：系统 `speechSynthesis`（复用现有 `speak()`），不预生成音频文件。
6. 「学一学」卡念法：字 + 拼音 + 例词（「日，rì。日出，生日，日子。」），不念卡片上那句书面语。
7. 控制件：每题「🔊 再念一遍」+ 家长中心朗读开关，两个都要。
8. 验收：先过一个关，iPad 上实测再定语速与停顿，不一次做完全量。
9. v1 不补图标选项的 `say` 数据；补不补，看 v1 实测结果。

## Decisions so far

<!-- 关闭一张票就往这里加一行，指回持有细节的那张票 -->

- [30+ 种题型各自的朗读文本在哪](issues/02-kind-narration-inventory.md)：30 个 case / 实存 29 种；现有 4 个 🔊 念的都是卡片不是题面；715 个纯图标选项；数据类型五花八门，必须按 kind 分支提取；挂点定在 `afterStepRender()`。
- [16 条「没有天然念法」的题型逐条拍板](issues/09-ambiguous-kind-narration.md)：16 条默认念法全接受；mappuzzle 只念题面、pattern 只念题面 +「看上面的图片」、clock 把 `3:00` 转写成「3 点」，三条带兜底，实测再纠。
- [家长中心的朗读开关长什么样](issues/04-parent-voice-switch.md)：总开关 + 语速滑块（0.6-1.0，默认 0.8），保留每题再念一遍，孩子端不加静音键，默认开，家长中心写一句「先看侧边静音开关」。
- [iPad Safari 的 speechSynthesis 能自动播到哪一步](issues/01-ipad-tts-behavior.md)：免手势朗读不成立，必须在进关点击的同步栈里念第一句；`cancel()` 后紧跟 `speak()` 会被吞，禁止同 tick 与 `onend` 串接；静音开关会静音且不可检测；只能拿到 compact 音色。

## Not yet specified

- 语速与停顿的最终数值：v1 用的是 `rate=0.8` + 标点控节奏；票 06 实听后可能要试 2-3 组速率。
- 音质上限：网页只能拿 compact 音色，实测若孩子听不清，要不要回头做预生成音频（现在划在 Out of scope，
  那样得重开一张图，包体也会变大）。
- 若补 `say` 数据：715 条文案怎么审（模板批量生成 vs 逐条人工），要不要顺带把 `options[].text` 补上让选项也显示文字。
- 棋盘/战斗模式下朗读与掷骰、掉心动画的抢声怎么排优先级。
- 拼音 `blend` 的声调：`speak()` 走 `pyConvert`，ba/bo/bu 会被念成「八/波/不」—— 是有意路由还是误伤，票 06 实测才知道。
- `sudoku` / `pattern` / `spotlight` 三种题型缺可念文本，补字段要动 `gen_content.py`；补不补取决于票 06（同 715 个图标选项那笔账）。

## Out of scope

- 主页 / 关卡列表 / 收集册的语音引导（孩子还能靠图标走，不在本次范围）。
- 掷骰、金币、掉心、结算的解说，以及答对表扬语音。
- 预生成音频文件（音色统一但包体变大；本次选系统 TTS）。
- Swift 原生端朗读实现（AGENTS.md §1）。
- 拼地图渲染 bug：票 02 顺带发现 7 个 `mappuzzle` 步骤渲染器读 `st.pieces`、生成器只产 `regions`，一张拼块都不渲染。
  这是既有缺陷，与朗读无关，不在本图路线上，另开修复。
