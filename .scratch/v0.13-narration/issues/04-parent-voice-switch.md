# 家长中心的朗读开关长什么样

## Question

「家长中心能一键关掉朗读」已经定了，形态还没定。要拍的是：

1. 家长中心（`renderParent`）里放什么：一个总开关 / 总开关 + 语速滑块 / 再加分学科开关？
2. 关掉之后，「🔊 再念一遍」按钮还留着吗（留着等于单次可念，不留等于彻底静音）？
3. 孩子端要不要也能一键静音（关卡右上角一个喇叭图标，和「再念一遍」分开）？
4. 默认值：出厂默认开（4 岁孩子是主要用户，默认关就等于没做）。

参考：家长中心现有的护眼时长与「从头开始」都在 `.scratch` 之外的 `renderParent()`；
收集册 7 组卡片的 🔊 手动朗读仍在（本票不动它）。

**票 01 补进来的一条**（要一起拍）：iPad 侧边静音开关会静音朗读，而网页检测不到。
家长中心要不要写一句「没声音时先看一眼侧边开关」的说明？还是干脆不写、靠你口口相传？

HITL：需要用户拍板。

## Answer

用户 2026-10-19 答复「B」。

- 家长中心放 **总开关 + 语速滑块**（不加分学科开关）。滑块范围 `0.6 - 1.0`，默认 `0.8`（与现有 `speak()` 一致，票 06 实测后再定最终默认值）。
- 每题「🔊 再念一遍」保留；总开关关掉后它也不出声——等于彻底静音，不再额外做静音按钮。
- 孩子端不加独立的静音/喇叭开关（关卡界面已经够满，且孩子会乱按）。
- 出厂默认 **开**。
- 家长中心写一句「没声音时先看一眼 iPad 侧边的静音开关」（票 01：静音开关会掐掉朗读且 JS 检测不到）。
- 状态沿用现有 `S` + `save()` 持久化；语速值与开关一起存。
