# 16 条「没有天然念法」的题型逐条拍板

## Question

票 02 盘出 16 种题型没有「念题面 + 念选项」这种天然读法（数独、拼地图、写字、看影子、望远镜、排排队、
分分类、照顺序、记忆翻牌、点点看、数骰子、时钟、扑克、拼读、学一学卡、字母卡），已逐条给了默认念法，
**建议整体接受默认，只在你不认同的那几条上标出来**：

| 题型 | 默认念法 |
|---|---|
| 数独（sudoku） | 念题面 + 「这一格该放什么？」+ 空格行列位置；四行图标名靠题面文字覆盖 |
| 拼地图（mappuzzle） | 题面本身是「拼一拼：把中国地图的六块拖回雄鸡轮廓」，念题面即可，块名不念 |
| 写字（write） | 念「跟着笔画写一遍：日」+ 第一笔名称 |
| 看影子（shadow） | 念题面；选项只念序号 |
| 望远镜（spotlight） | 念题面 + 目标名（从题面兜，图标 id 转不了中文） |
| 排排队（lineup）/ 照顺序（sequence） | 念题面；序列本身不念（念出来等于报答案） |
| 分分类（sort）/ 记忆（memory） | 念题面 + 每次翻/放的动作提示 |
| 点点看（tapall） | 念题面（点几次、点什么），选项只念序号 |
| 数骰子（count-dice）/ 时钟（clock） | 时钟把「3:00」转写成「3 点」，不能直接念冒号 |
| 扑克（cards）/ 拼读（blend） | 念题面 + 选项（数字/字母本身可念） |
| 学一学卡（teach）/ 字母卡（letter） | 已定：字 + 拼音 + 例词 |

要拍的就一件事：**全接受，还是哪几条要改**。同意的话我在票 05 里照这张表实现，票 06 实测时再纠。

HITL：需要用户点头或点名改哪几条。

## Answer

用户 2026-10-19 答复「按照你的建议来」→ **16 条默认念法全接受，无例外**。

落地时按上面的表实现，另有三条要带兜底，避免「念法定了但东西念不出来」：

1. **拼地图（mappuzzle）**：默认是「只念题面、不念块名」，正好绕开了它现在渲染不出拼块的字段 bug
   （`st.pieces` vs `regions`，见票 02 的 Answer，已划出本图范围）。若之后有人先修了那个 bug，块名仍然不念——
   念块名等于报答案。
2. **找规律（pattern）**：9/11 题面没复述序列、`seq` 又全是图标 id，所以只念题面 + 一句「看上面的图片」，
   不硬造序列念法。这条在票 06 实测时重点听——如果孩子还是听不懂题干，再回来改。
3. **时钟（clock）**：渲染层做转写，`3:00` 念「3 点」、`3:30` 念「3 点半」，禁止直接念冒号。

风险都集中在票 06 的实测里收口：念法本身可改，不锁死。
