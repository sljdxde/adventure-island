# 朗读稿样张：孩子到底会听到什么

## Question

在写渲染钩子之前，先把 4 个代表步骤的朗读稿**逐字**写出来，让人对着念一遍就能判断
「4 岁孩子听不听得懂、会不会太啰嗦」。样本：

| 步骤 | 题型 | 为什么选它 |
|---|---|---|
| `cn-0-t` | 学一学卡 | 96 张卡里最典型的「字 + 拼音 + 例词」 |
| `cn-0-l` | 听音找图（listen） | 选项是图标、内容就是答案，只念序号 |
| `math-0-c` | 数一数（count） | 题面长、要孩子动手点 |
| `en-0-q` | 英语看图选（quiz） | 中英混排，考语音路由 |

产出要求：

- 每步逐句写出朗读文本，标出停顿位置与序号念法（「第 1 张」还是「第一张」）
- 列出「念起来别扭 / 会歧义 / 太长」的地方，各给一个替代念法
- 便宜的形态就行：一份 markdown 稿，或一个能逐句高亮的静态小页；不要接进 `index.html`

HITL：稿子要用户念出声来判断，不是给工程师看的。

## 草稿（2026-10-19，待用户判）

一次性原型：`.scratch/v0.13-narration/proto/narration-script.html`（双击打开，点 ▶ 听）。
